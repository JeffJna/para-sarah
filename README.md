# 💝 Para Sarah Ariane

> ⚠️ **SPOILER ALERT, Sarah!** Se você chegou até aqui antes da hora… finge que não viu e volta depois. 😄

Um presente de Dia dos Namorados feito com código e amor por **Jefferson Almeida**.

## O que é

Uma jornada cinematográfica pela nossa história: tela de cadeado com a chave do nosso coração, contador ao vivo desde **23/07/2017**, capítulos com 75 fotos, trilha sonora, quiz e uma carta no final.

## Como personalizar

Tudo editável em **`js/config.js`**: textos dos capítulos, perguntas do quiz (procure os ⚠️), a carta final e a senha.

## Rodar localmente

```bash
python -m http.server 8000
# abra http://localhost:8000
```

## Deploy

Push na branch `main` → GitHub Actions publica automaticamente no GitHub Pages (`.github/workflows/deploy.yml`).
